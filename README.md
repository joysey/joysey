# Hi, I'm Jack 👋

I build tools that help people keep, organize, and reuse the knowledge they create with AI.

My current focus is the layer between AI conversations and long-term personal knowledge:

**ChatGPT / Claude / Gemini / Perplexity / Grok / Genspark  
→ Markdown / Notion / Obsidian  
→ Your own knowledge base**

## What I'm building

### 🧠 AI Exporter Hub for Obsidian

Turn exported AI conversations into a private, searchable, local-first knowledge hub inside Obsidian.

- Multi-platform conversation library
- Projects, categories, inbox, favorites
- Conversation reader
- Rediscovery
- Markdown as the source of truth

→ [GitHub](https://github.com/joysey/ai-exporter-hub-obsidian)

### 📦 AIExportHub

Export and back up conversations from multiple AI platforms to Notion, Markdown / Obsidian, and PDF.

→ [AIExportHub](https://chatgpt2notion.com/)
